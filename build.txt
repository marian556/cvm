This project is a customizable,  lightweight and fast C like general purpose virtual machine and scripting language with 
fast binding/calls to C/C++.

For the language motivation and the features see readme.txt.

You can import this project folder into eclipse on ubuntu.

it requires at least -std=c++20, it was test to build with -std=c++26 switch.

You can use either command line to buil cvm compiler/interpreter

cvm$ g++ -std=c++20 -O3 src/main.cpp src/global_funcs.cpp src/libcvm/*.cpp -o cvm -lboost_chrono -lboost_filesystem

cvm$ ./cvm examples/bisect_sqrt7_func.cvm

or you can use Eclipse and load folder with .cproject file
Then when make Release with make file os create in eclipse.
you can use makefile system with 'make all' 

Note:This work uses computed goto with gcc compiler, Visual Studio compiler mvc lacks computed goto so there is a 30% slower 
alternative solution using switch/branching in virtual machine. It should work on Microsoft Visual Studio , but it was not yet tested.

Project tested on GNU/Linux/ubuntu 18.04.01 LTS (bionic) with 64 bit g++ (Ubuntu 7.3.0-16ubuntu3) 7.3.0 
and debian/trixie GNU/Linux 13

This project uses boost/spirit X3 parser in an essential way. Project was tested on boost 1.69.0 and 1.83
(you may want to use and you can try to use your default system version of boost first)
and is compiled with C++20 at least, it was tested and works with c++26 dialect

on ubuntu and debian install it with
sudo apt install libboost-dev libboost-chrono-dev libboost-filesystem-dev


...Project is heavily adapted and extended from example calc9 in boost documentation:
/usr/share/doc/libboost1.65-doc/examples/libs/spirit/example/x3/calc/calc9/
...or..
~/boost_1_69_0/libs/spirit/example/x3/calc/calc9/

...although spirit X3 parser is header only if you don't use your system boost you need to 
...proceed building boost,because we need boost_chrono and boost_filesystem at least to build...
...you may have to configure your build system to include boost include path...
